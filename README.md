# YEG-YYC-MobileApp

## 📱 Mobile Development Assignment - Expo Sign-In & City Navigation

Welcome to **YEG-YYC-MobileApp**, a React Native project built using **Expo** for the Mobile Development course. This assignment demonstrates user authentication, input validation, and navigation, along with an interactive city guide for **Calgary** and **Edmonton**.

## 🔹 Features

✅ **User Authentication** – A sign-in form with username and password validation using **regex**.  
✅ **Data Storage** – User credentials stored in a JSON file (`credentials.json`).  
✅ **Error Handling** – Alerts for incorrect inputs, username mismatches, and password validation failures.  
✅ **Navigation** – Upon successful login, users land on a welcome screen with tab navigation.  
✅ **City Pages** – Each tab (Calgary & Edmonton) includes:  
   - A city image  
   - A **clickable link** to the official city website  
   - Interesting information, styled using a dedicated component.  
✅ **Code Reusability** – Components for displaying city links and information are modularized using **props**.  
✅ **User-Friendly UI** – Styled with a clean and responsive design for an intuitive experience.  

## 🔹 Technologies Used

- **React Native** (Expo)
- **JSON Data Handling**
- **Type Script**


## 🔹 Usage Instructions

1. **Sign-In:** Enter a valid username and password based on the criteria:
   - Username: At least 5 characters.
   - Password: At least 8 characters, including one uppercase letter, one lowercase letter, one number, and one special character.
2. **Navigation:** After successful login, navigate between "Calgary" and "Edmonton" tabs.
3. **City Pages:** Click the "Go to city page" link to visit the official city websites:
   - [Calgary](https://www.calgary.ca/home.html)
   - [Edmonton](https://www.edmonton.ca/)
